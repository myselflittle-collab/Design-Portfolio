# ButterSkin — skincare, made softer

ButterSkin is a standalone skincare and beauty app concept created as a Behance portfolio case study. It explores how product discovery, simple routines, and skin journaling can feel calm, clear, and personal.

## Open the prototype
Open `prototype/index.html` in a browser. It is a self-contained responsive HTML/CSS/JavaScript prototype with no build step.

## Included in this concept
- Responsive desktop and mobile layouts
- Overview dashboard and daily routine checklist
- Product discovery catalogue with category filters
- Product detail modal and saved-product interactions
- Editable demo skin preferences and a journal note
- Case study narrative and design system notes

## Visual direction
Warm butter paper, muted botanical green, soft clay, editorial serif headlines, rounded cards, and gentle product-display shapes. The experience favours supportive language over perfection-driven beauty messaging.

## Important scope note
ButterSkin is a fictional portfolio concept. Product names, prices, routine steps, and skin preferences are illustrative demo content, not real products or medical advice. Interactions are local to the current browser session; there is no account system, backend, checkout, or health diagnosis.

## Project independence
This concept lives in its own folder and its own branch, `butterskin-concept`. It does not modify the MoneyMines project.
